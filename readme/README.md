# 🎌 Anime Blog - Laboratorio de Refactorización con Bootstrap

¡Bienvenido/a al repositorio de nuestro proyecto! Este laboratorio de desarrollo front-end tiene como objetivo principal poner en práctica la **refactorización** de un sitio web existente (un blog de anime), transformando su diseño y maquetación mediante la implementación del framework **Bootstrap**.

---

## Objetivos del Laboratorio

El propósito de este proyecto no es empezar desde cero, sino mejorar la base existente estructurando el sitio con los siguientes componentes clave de Bootstrap:
* **Navbar:** Navegación optimizada y responsiva entre las páginas.
* **Sistema Grid (Rejilla):** Distribución de contenido adaptable a cualquier pantalla.
* **Componentes de Bootstrap:** Uso de tarjetas (*cards*), contenedores y elementos preestilizados.
* **Formulario:** Maquetación limpia de la sección de contacto.
* **Alertas:** Implementación de avisos visuales para el usuario.

---
