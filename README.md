# AD-14-1 - LAB: Refactorización del Blog

Versión para estudiantes en español.

Este proyecto es una base para practicar Bootstrap. El objetivo no es empezar desde cero, sino refactorizar un sitio de blog usando componentes de Bootstrap, sistema Grid, Navbar, formulario y alerta.

## Archivos principales

- `index.html`: página de inicio.
- `about.html`: página Quiénes somos.
- `contact.html`: página de contacto.
- `style.css`: estilos personalizados generales.
- `script.js`: interacción para mostrar la alerta de “Mensaje enviado”.
- `instructions.md`: instrucciones completas del laboratorio en español.
- `Wireframe-Backup/`: imágenes de apoyo del wireframe.

## Cómo abrir el proyecto

1. Abre esta carpeta en VS Code.
2. Abre `index.html` con Live Server o directamente en el navegador.
3. Revisa las tres páginas: Inicio, Quiénes somos y Contacto.
4. Sigue las tareas indicadas en `instructions.md`.

## Entrega esperada

El equipo debe entregar un blog refactorizado con Bootstrap, respetando el wireframe y sin errores evidentes.
